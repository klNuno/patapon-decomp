# Your own dump

Put an image of your own Patapon UMD here, `.iso` or `.cso` (any name), and only one. `make check-disk` decompresses a CSO into `build/disk.iso`, copies the files into `extract/`, prints the UMD id, the PARAM.SFO fields, the format of `BOOT.BIN` and `EBOOT.BIN`, and the redump disc it matches (`config/redump.tsv`). Nothing in this folder is tracked.
